01 / FÅ FILEN

Last ned oppgavene

Vi lager filen oppgaver.js med alle oppgavene slik du har redigert dem.

Filen lastes ned på din datamaskin. Dette publiserer ikke automatisk.

02 / OPPDATER GITHUB

Bytt ut den gamle filen

  1. Åpne ditt kodeverkstedet-prosjekt på GitHub ↗.
  2. Velg Add file → Upload files og last opp den nye oppgaver.js.
  3. Bekreft endringen med Commit changes.
Hvis GitHub ikke lar deg erstatte filen

Åpne oppgaver.js i GitHub, klikk blyanten, trykk Ctrl+A / Cmd+A i editoren og lim inn innholdet fra knappen nedenfor. Lagre med Commit changes. Du trenger ikke å skrive eller forstå koden.

03 / FERDIG

Sjekk elevsiden

Etter at GitHub Pages har publisert endringen, åpner du elevsiden og oppdaterer nettleseren.

Se elevsiden ↗

Del den vanlige elevlenken – ikke adressen til admin.html.

TRYGG LAGRING

Ta vare på arbeidet ditt

Utkast lagres automatisk kun i nettleseren på denne enheten. Bruk en sikkerhetskopi hvis du vil fortsette på en annen PC eller hvis nettleserdata kan bli slettet.

Lærerrommet har ingen innlogging. Alle kan åpne redigeringssiden, men bare noen med tilgang til ditt GitHub-prosjekt kan publisere endringer. Ikke skriv elevenes private opplysninger i oppgavene.
